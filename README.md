🚗 Car Dealership

Car Dealership is a front-end application with HTML, CSS and JavaScript, designed to provide a modern experience for browsing and buying cars online. The platform simulates a car dealership, where users can view, explore and buy different vehicles in a clean and interactive UI.

✨ Main Features

🚘 Car display with categories and descriptions

🛒 Shopping functionality – add cars to cart

🎨 Modern and visually appealing design

💻 Clean and interactive front-end – using JavaScript for interactions

🛠️ Technologies used

HTML5 – for page structure

CSS3 – for modern styling and design

JavaScript – for interactivity and dynamic logic

🎯 Project goal

This project is built as a practical front-end exercise, demonstrating:

skills in creating a modern and attractive UI

managing interactivity with JavaScript

building a pleasant and functional user experience for browsing and buying cars online
